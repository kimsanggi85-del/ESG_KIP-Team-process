# IATF 16949 KPI 관리 시스템 — 배포 구조

## 폴더 구조 (이 구조 그대로 유지)

```
KPI_시스템/
├─ index.html          ← 메인 (이 파일을 열거나 GitHub Pages 루트에 배포)
├─ README.md
└─ lib/                ← 라이브러리 (index.html 과 같은 위치에 있어야 함)
   ├─ chart.umd.js         Chart.js 4.4.1      (추이 그래프)
   ├─ xlsx.full.min.js     SheetJS 0.18.5      (엑셀 내보내기)
   ├─ html2canvas.min.js   html2canvas 1.4.1   (화면 캡처)
   ├─ jspdf.umd.min.js     jsPDF 2.5.1         (PDF 출력)
   ├─ pptxgen.bundle.js    PptxGenJS 3.12.0    (PPT 출력)
   ├─ jszip.min.js         JSZip 3.10.1
   └─ email.min.js         EmailJS 3.11.0      (메일 알람)
```

## 로드 방식

1순위 `./lib/` 로컬 파일 → 실패 시 자동으로 CDN(cdn.jsdelivr.net) 폴백
→ 둘 다 실패하면 화면 하단에 **빨간 경고 배너**로 어떤 라이브러리가 빠졌는지 표시

사내 폐쇄망(인터넷 차단) 환경에서도 `lib/` 폴더만 있으면 전 기능 정상 동작.

## 배포 방법 (GitHub Pages)

```bash
git add index.html lib/ README.md
git commit -m "라이브러리 로컬화 + 추이분석 전체조회 오류 수정"
git push
```
※ `lib/` 폴더가 `.gitignore` 에 걸려 있지 않은지 확인할 것.

## 로컬 실행

`index.html` 더블클릭 (file:// 로도 동작).
단, Supabase 접속이 필요하므로 인터넷 또는 사내에서 Supabase 접근이 가능해야 함.

## KPI 실적 자동 등록 (SmartFactory 연동 — 품질·생산)

계산식은 `sf_kpi.js` 한 곳에 있고, 화면 버튼과 자동 등록 작업이 같이 씁니다.

| 부서 | KPI | 원자료 (SmartFactory) | 산식 |
|---|---|---|---|
| 품질 | 사내공정불량률(거래처) | 불량관리 월간보고 누적자료 | 불량수 ÷ 검사수 × 1,000,000 |
| 품질 | 수입검사 불량률(공급사) | 수입검사 기록 | 불합격 LOT ÷ 입고 LOT × 1,000,000 |
| 품질 | Q-cost 비용 | 월간보고 손실비용 + 선별비용 | 합계(원), 단위가 만원이면 ÷ 10,000 |
| 생산 | 생산계획 대비 실적 달성률 | 생산일보 실적 · MES 목표수량 | 실적 ÷ 목표수량 × 100 |
| 생산 | 설비 가동률 | 생산일보 | 가동시간 ÷ 실근무 — 일자별 평균의 평균 (생산일보 월간 보고서와 같음) |
| 생산 | 효율 | 생산일보 | 실적 ÷ 가능수량 — 일자별 평균의 평균 (생산일보 월간 보고서와 같음) |

- 예방보전 준수(계획 건수 자료 없음)와 MTTR 달성률(기존 입력값과 산식 불일치)은 자동 산출하지 않습니다 (직접 입력).
- 생산계획 달성률은 생산일보에 그 달 MES 목표수량이 입력돼 있어야 산출됩니다.
- **자동 등록**: `.github/workflows/sf-quality-sync.yml` 이 매일 07:17(한국시간)에 `scripts/sf_kpi_sync.mjs` 를 실행해 지난달·전전달 실적을 저장합니다.
  - 원자료에 그 달 자료가 없으면 건너뜁니다.
  - 직접 입력한 실적은 덮어쓰지 않습니다. 비고가 `[SF]` 로 시작하는 자동 등록분만 원자료가 바뀌면 갱신됩니다.
  - Actions 탭에서 수동 실행 가능 (`dry_run` = 1 이면 저장 없이 계산 결과만, `months_back`·`depts` 로 범위 지정).
- **수동 불러오기**: 실적 입력 탭의 [🔄 품질·생산 실적 SmartFactory에서 불러오기] → 값 확인 → [💾 전체 저장].
- 불량관리 월간보고는 수정 후 **서버 동기화**를 해야 반영됩니다.
